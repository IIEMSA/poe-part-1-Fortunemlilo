# POE_PROG6212: Contract Monthly Claim System (CMCS)

## Overview
This project is a **Contract Monthly Claim System (CMCS)** developed using **WPF (.NET Core)**. It serves as a front-end prototype that allows **Lecturers** to submit monthly claims and **Programme Coordinators** or **Academic Managers** to review, approve, or reject claims.

The system provides a user-friendly and intuitive interface to streamline the claim process and ensure that lecturers are paid based on the hours worked and hourly rates provided.

## Features
The system has two main interfaces:
1. **Lecturer Dashboard**
   - **Submit New Claims**: Lecturers can submit their monthly claims by specifying hours worked and their hourly rate.
   - **Upload Supporting Documents**: Allows lecturers to upload documents to support their claim (feature to be implemented).
   - **View Claim History**: Lecturers can see a list of previously submitted claims, along with their status (pending, approved, rejected).

2. **Coordinator Dashboard**
   - **View Pending Claims**: Programme Coordinators and Academic Managers can view pending claims that need to be approved or rejected.
   - **Approve/Reject Claims**: They can take action on each claim (approve or reject) and track the claim's status.
   - **View Approved Claims**: The dashboard also displays all the claims that have been approved.
